# Linux Bash Projects 🐧

A collection of practical Bash scripting projects built while practicing Linux administration and automation.

## 📂 Projects

### 1. User Onboarding Tool
- Create a new user
- Set user password
- Add user to the sudo group
- View user information
- Lock and unlock user accounts
- Delete user accounts

### 2. Server Health Monitor
- Check disk usage
- Check memory usage
- Monitor CPU load
- View logged-in users
- Check system uptime
- View running services
- Display current date and time

### 3. Backup Automation Tool
- Create compressed backups using `tar` and `gzip`
- Automatic date-based backup naming
- View available backup files
- Delete old backup files

### 4. Log Analyzer Tool
- View log files
- Count lines
- Count words
- Search keywords
- Display first 10 lines
- Display last 10 lines

### 5. File Permission Manager

- # 6. User Report Generator

A simple Bash script to generate Linux user reports using a menu-driven interface.

- View total users in the system
- Display users with Bash shell
- Show currently logged-in users
- Generate and save a user report with the current date
- Menu-driven interface
